# company-valuation-system
A股"质量与估值"错配筛查器——从质量与估值两个维度筛选个股，用历史分位量化错配程度，附离线 HTML 看公司价值判定系统（Company Valuation System）是一个面向 A 股的、离线优先的研究工具包。它对每只股票从两个维度打分——经营质量与估值——再用价值因子（E/P）的长期分位来对横截面错配程度排序。所以这里的"便宜"，是指相对公司自身历史和同行的便宜，而不只是绝对估值低。  仓库分三层：核心算法（core/）、数据层与适配器（dataio/），以及一个可直接运行的 demo 和一个不需要服务器就能打开的离线 HTML 看板（board/valuation_board.html）。数据来自公开的 A 股行情源（AKShare），不打包任何数据库
