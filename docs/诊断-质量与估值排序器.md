# 诊断：质量与估值排序器

这篇记录的是质量加估值排序器的一次诊断运行，环境是 Windows 加 PowerShell 下的 `py -3.12`，Python 3.12 加 numpy，数据源是只读打开的 A 股主库。这是研究讨论，不构成投资建议。下面的命令和输出都是一次真实运行的结果，那次快照日是 2026-10-09、财务报告期 20260630、股票池 5371 只，比现在的最新快照早几天，所以数字和当前不同，属于数据漂移。

## 运行命令与结果

排序并写清单，以及单独跑诊断：

```powershell
py -3.12 quality_value_screener.py --mode rank --top 40 --watchlist watchlist.csv --out rank_out.txt
py -3.12 quality_value_screener.py --mode diag --out diag_out.txt
```

两条命令都正常结束，退出码 0，没有报错。排序那条写出 `watchlist.csv`（2686 行）和 `rank_out.txt`（3930 字符），诊断那条写出 `diag_out.txt`（1476 字符）。

开发过程中撞到过一个真实错误并修掉了。首次跑 `--mode diag` 时报 `AttributeError: 'sqlite3.Connection' object has no attribute 'fetchall'`，退出码 1，原因是 `run_forward_test` 把 `Connection` 当游标传给了 `load_valid_dates`。修法是函数内先 `cur = con.cursor()`，修好后诊断正常产出。

质量分和估值分都是池内百分位，所以均值天然接近 50、分布形状天然均匀，这是口径产物，不代表分数都差不多。错配度要求 EPS 和价格都为正，有效值 4089 个，中位数 -0.31，说明按这个口径，池内偏便宜的一侧更厚，受行业 PE 中位数偏高影响；最大值 6.58 是缩尾后的极值。PE 原值散得很开，正负数千，已经靠缩尾处理。

## 能做的简单检验

横截面相关里，质量分和估值分的相关系数只有 0.118，弱正相关，两个分基本正交，提供的是近似独立的信息。质量分和错配度的相关是 -0.436，质量高的股票错配度更低，也就是更便宜。估值分和错配度的相关是 -0.787，方向一致，因为估值分本身含错配成分，偏高属预期。质量分和 PE 的相关是 0.188，质量高的 PE 略高，符合好公司贵一点。估值分和 PE 的相关是 -0.302，PE 越低估值分越高，方向正确。

前向收益检验用一个锚点日 2026-08-31，持有到 2026-10-09，25 个交易日，时点守卫打开。IC 上，质量分是 -0.081，估值分是 0.151；质量分三分组从低到高是 -2.17%、-2.18%、-4.12%，低减高差 +1.95%；估值分三分组从低到高是 -3.83%、-2.45%、-2.19%，低减高差 -1.63%。在这个窗口里，便宜方向和收益正相关（估值分正 IC），高质量在这个窗口是轻微负 IC。但这是单锚点、单窗口、25 个交易日、没扣费、没做多重检验的结果，按研究方案的标准应该判 undetermined，不能据此宣称因子有效，记录它只是为了留一条可复现的一致性观察。

## 样本限制

财务期数太少，`fin_report` 只有 20260630 和 20260331 两期，做不了质量稳定性这类东西，比如连续为正年数和增量 ROIC。估值历史缺失，`valuation_daily` 那次只有三个交易日，没有 PE、PB 历史分位，估值分只是当期横截面。绝对估值的输入缺，没有账面价值、现金流、负债、股利、分析师预期和融券数据，质量六维里现金流、资本配置、财务稳健多数项算不了，本版本用可得代理取代，缺失处理在数据边界那篇里逐条标注过。EPS 年化按半年报乘 2 简化，忽略季节性和季度波动，有偏。账面收益率是近似，净资产约等于净利除以 ROE，依赖 roe 口径（加权还是摊薄库里没区分）和 net_profit 口径，只能当量级参考。前向检验比较弱，单一锚点加单窗口加未扣费加未多重检验，而且锚点之后还有部分财报没披露，时点守卫会把 `pub_date` 晚于 2026-08-31 的票剔除，代价是牺牲了样本。全市场日 K 只有约 275 个有效交易日，长周期样本不足。涨跌停、一字板、ST 剔除口径和冲击成本都没进收益检验。

本文所有命令和输出都是真跑原文，研究讨论，不构成投资建议。
