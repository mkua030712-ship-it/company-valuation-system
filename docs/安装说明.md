# 安装说明

这份文档面向从没跑过这个项目的人。目标只有一个：把代码拿到手、装好依赖、跑通 demo 看到结果，全过程大约五分钟。跑通 demo 不需要数据库，要跑真实全市场，才需要自己准备 `astock.db`。

这是一个普通的 Python 项目，不是要装进系统的软件。你把代码 clone 或解压到任意文件夹就行，想删就删，不留残留。唯一的依赖是 numpy，可以用 pip 装，也可以建个虚拟环境把依赖装在项目里，不污染系统 Python（推荐但非必须）。项目支持 Python 3.10 以上，我们在 3.12 上实测过。

## 装 Python 和依赖

先确认有 Python。Windows 上到 python.org 下载安装包，安装时勾上 Add python.exe to PATH，装好后 `python --version` 或 `py -3.12 --version`；macOS 上可以 `brew install python@3.12`，或到 python.org 下载，验证 `python3 --version`；Debian 或 Ubuntu 上 `sudo apt update && sudo apt install -y python3 python3-venv python3-pip`，验证 `python3 --version`。只要版本号在 3.10 以上就行。

文档里 `python`、`python3`、`py -3.12` 三种写法等价，按系统选一个，Windows 只装了 Launcher 的话用 `py -3.12`。

拿到代码可以直接 clone，没有 git 也可以在仓库页面点 Code、Download ZIP，解压后进文件夹，效果一样。

```bash
git clone <仓库地址>
cd company-value-system-final-2026-10-12
```

想隔离环境的话建虚拟环境：

```powershell
# Windows PowerShell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
# 被执行策略拦住就先运行： Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```
```bash
# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

激活成功后命令行前面会出现 `(.venv)`。不想激活也可以直接调解释器，Windows 用 `.venv\Scripts\python`，macOS 和 Linux 用 `.venv/bin/python`。不建虚拟环境也可以，依赖会装到系统 Python。

然后装依赖：

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -c "import numpy; print('numpy', numpy.__version__)"
```

`requirements.txt` 里只有一行 numpy，其余全是标准库，包括 sqlite3、argparse、math、os、csv、collections，不需要 pandas、scipy、sklearn。本项目是纯 Python，不需要 make，不需要编译，也不需要装进系统。

## 跑 demo 验证

```bash
python demo.py
```

它读仓库自带的脱敏样例 `examples/data/sample_valuation_snapshot.csv`，跑一遍行业相对倍数法加秩合成错配，打印一张贵贱排序表，最后输出 `DEMO OK ✔`。这个样例是手造脱敏数据，不是真实行情，只用来验证安装。demo 只用 numpy 和标准库，跟真实数据库无关，它演示的是主脚本 `--mode value` 里"行业 PE 中位数到内在价值再到错配秩"这条链路，因为样例没有 EPS 明细，用 EPS 约等于 price 除以 pe 做了简化，等价于比较相对 PE。

看到 `DEMO OK ✔` 就说明环境装好了、代码能跑通。Windows 默认的 GBK 控制台会自动把 ✔ 降级成 `DEMO OK √`，属正常，不是报错。如果你跑出了 `UnicodeEncodeError`，那是历史版本在 GBK 控制台的已知问题，本版已经修好。

## 接真实数据

全量数据因体积不入库，`*.db` 和大 `*.csv` 都在 `.gitignore` 里，仓库不含任何真实数据库，要跑全市场得自己准备。需要两个 SQLite 库，都是只读使用。`astock.db` 放行情、财务、估值快照、行业和股本，放在 `data/astock.db`，或用 `--db <path>`，或设环境变量 `ASTOCK_DB`；`valuation_hist.db` 放逐日历史估值序列，用 `--hist-db <path>` 指定，默认取脚本同目录下的 `valuation_hist.db`。表结构和字段见 `dataio/schema.md`，数据可以从 akshare、东方财富、新浪、腾讯这些公开源采集，按字段落库即可，不用改脚本。

准备好之后常用命令如下，更细的字段和列的含义、真实输出示例都在 `使用说明.md`。

```bash
# 全市场：错配 + 检验 + 历史分位
python mispricing_screener_v2.py --mode both --db data/astock.db --hist-db data/valuation_hist.db --out v2_out.txt

# 单只 / 几只票
python mispricing_screener_v2.py --mode value --codes 600519,000858 --out one.txt

# 质量 + 估值排序（写文本 CSV 清单）
python quality_value_screener_v2.py --mode both --top 40 --watchlist watchlist.csv --out qv_out.txt

# 自身历史估值分位
python valuation_percentile.py --hist-db data/valuation_hist.db --top 25 --out pct_out.txt
```

## 常见问题

报 `python: command not found` 或找不到命令，Windows 试 `py -3.12`，macOS 和 Linux 试 `python3`。`pip install` 很慢或超时，加国内镜像，比如 `python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`。PowerShell 不让激活虚拟环境，先 `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` 再激活，或直接用 `.venv\Scripts\python` 调解释器。demo 报 `ModuleNotFoundError: numpy`，说明依赖没装好，或者用的不是同一个 Python（虚拟环境没激活），先 `python -c "import numpy"` 确认。跑真实脚本报找不到数据库是正常的，仓库不带数据，按上一节准备 `astock.db` 并用 `--db` 指过去。Windows 控制台中文乱码，先执行 `chcp 65001` 或设 `$env:PYTHONIOENCODING="utf-8"`，脚本输出文件本身是 UTF-8。
