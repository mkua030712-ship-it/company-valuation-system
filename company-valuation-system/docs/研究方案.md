# 股票市价与内在价值的错配：研究方案

版本 v1，日期 2026-10-10。这是一份学术兼工程的研究方案，中性、可检验、可复现，可以拿给导师或同行看。数据环境是本地只读的 A 股 SQLite 主库，加一套纯 numpy 写的统计工具。本文只写能核实的文献和方法，核对不到的只写方法名，不编造论文标题、作者或统计数字，所有本地数据描述都来自对库的实测查询。它是研究讨论，不构成投资建议。

## 问题定义

整个问题得从一件事说起：内在价值不可直接观测。任何"某股被高估或低估"的说法，都隐含了一个估值模型（DCF、剩余收益、可比倍数等等）和一整套假设（增长率、折现率、终值、可比集）。换一套假设，结论可能翻转。所以"谁贵谁便宜"本身不是科学命题，它不可证伪，也没法在横截面上统一比较。

能检验的命题是另一个：由某个错配度量刻画出的高分组和低分组，能否在风险调整后预测未来收益的横截面差异。把"错配"从判断句翻译成度量，再从度量翻译成对未来收益的预测力，问题才落到可检验的地面上。研究据此拆成三段：先度量，构造不依赖单一模型、或对模型假设稳健的错配指标；再预测，用横截面回归和分组组合检验度量与未来一到十二个月收益的关系；最后裁决，在交易成本与多重检验校正下判断预测力是真实边际还是数据挖掘。只有第三段通过，前面两段才有意义。这也是必须把统计显著性和经济显著性分开报的原因。

## 理论谱系

内在价值这一类是绝对估值，有三条主路。股利折现（DDM）最干净，但对不分红或分红不稳的公司直接失效，A 股大量成长期公司分红就少。现金流折现（DCF）适合现金流可预测、资本结构稳定的成熟公司，失效条件是终值项主导估值（占比常超过七成），WACC 和永续增速稍微一动估值就剧烈漂移，对周期性行业和早期公司几乎不可用。剩余收益模型（RIM）把估值锚在账面价值上，对终值的依赖弱于 DCF，理论基础是 Ohlson 1995 那篇（出处见文末），失效条件是会计质量差或账面价值不反映公允价值。这三类方法的共同问题是输入假设太多，不同研究者的估值区间可能相差数倍，而且估值日期不同导致不可比，它们适合单标的深度研究，不适合全市场横截面排序。

相对估值是第二类，包括可比公司或行业倍数（PE、PB、PS、EV/EBITDA），优点是数据需求低、可全市场批量算，失效条件是可比集本身被错误定价时，相对便宜可能只是整个行业都贵；行业分类口径影响很大，本库实测就有行业缺失的情况。还有历史分位，看个股或行业的 PE、PB 处在自身历史的什么位置，优点是对公司固有差异有控制，但需要一个致命的前提，就是长历史估值序列，而本机原来的估值快照只有几天，做不了历史分位。

收益侧是第三类，用来做风险调整。CAPM 是单因子，超额收益对 β 做调整，失效条件是规模、价值、动量这些异象解释不了。Fama-French 三因子加了规模和价值，五因子再加盈利和投资（五因子出处见文末）。q-factor 是另一套投资型因子模型（方法名，本次没核到确切出处，就不注年份卷期）。错误定价因子这一类把多个异象合成可交易的错配因子，代表是 Stambaugh、Yu、Yuan 的 Mispricing Factors（出处见文末），失效条件是合成权重依赖样本内拟合、容易过拟合，而且 A 股融券难、多空组合不可实现。最后一类是收益侧的错配度量，比如做空成本和融券费率、分析师预期误差与修正、异常收益、应计异象、复合错配评分，共同逻辑是错配的修复需要套利，而套利受成本和风险约束，成本越高、特质风险越大，错配越可能持续，A 股的约束是融券券源和做空成本数据本地缺。

| 层级 | 代表方法 | 定位 |
|---|---|---|
| 价值侧（估值） | DDM / DCF / RIM / 倍数 / 历史分位 | 直接给内在价值，但假设重、日期不可比 |
| 收益侧（风险调整） | CAPM / FF3 / FF5 / q-factor | 把收益差还原为是否已被已知风险解释 |
| 错配侧（合成） | 错误定价因子 / 异常收益 / 做空成本 / 分析师误差 | 把错配做成可交易、可检验的量 |

## 三种口径的对比

绝对估值口径直接比较价格和内在价值，可检验性弱，因为内在价值含模型假设，换假设就换结论；数据需求高，要现金流、债务、股利、WACC；复杂度中高；可靠度上单标的可参考，全市场排序不可靠，因为口径随假设漂移。

相对估值口径比较价格和可比集倍数，或者看估值的历史分位，可检验性中等，因为可比集的选择仍是自由度；数据需求中等，要价格、EPS 或净资产、行业分类、历史估值序列；复杂度低；横向可用，本原型已经跑通，历史分位则因为没有长序列暂时不可用。

风险调整后的超额收益口径，把候选度量的收益差对已知风险因子回归，看 alpha 是否显著，可检验性最强，因为它天然回答了"这是不是已知风险的代理"；数据需求是价格加因子构造所需的会计量；复杂度中等；可靠度最高，可以直接接检验管道。

按可检验性和可靠度排序，绝对估值最低，相对估值居中，风险调整超额收益最高。所以研究主线应放在后两种，绝对估值作为单标的深度分析的补充。

拿不到的得写清楚。长历史估值序列拿不到，估值快照只有几天，PE、PB 历史分位算不出来，这是相对估值口径最大的缺口。账面价值和归母净资产没有对应字段，RIM 的直接输入缺，脚本只能用净利除以 ROE 反推近似。现金流量表、负债明细、有息负债、资本开支都缺，标准 DCF 没法诚实计算。股利明细缺，DDM 算不了。分析师盈利预测与修正缺，对应的度量构造不出来。融券费率、做空成本和券源缺，做空成本类度量构造不出来，多空组合在 A 股也难实现。本地没有现成的 SMB、HML、RMW、CMA 因子序列，库里有 `sh000001`、`399001`、`399006` 这些指数可以自建市场因子，但因子本身要自己造。全市场完整日 K 只有大约 276 个交易日，即从 2025-08-19 起约 13.5 个月，再早的只是部分票池，不能用于严格的横截面长周期回测，这直接限制了十二个月及以上期限的样本量。

工具方面是够用的。数据采集有一套已封装 akshare、东方财富、新浪、腾讯接入的技能（含代理设置、防污染自检、交易日和幽灵日判据），想补历史估值可以从上游长期采集。统计工具有一套纯 numpy 手写的模块，包含逻辑回归、梯度提升树桩、Purged K-Fold、DSR 和 PBO、网格扫描，不用 scipy 和 sklearn。解释器用 `py -3.12`，带 numpy。结论是本机能做全市场日收益的横截面检验、价格类错配代理、行业和概念分组，以及龙虎榜和资金流这类另类数据的短窗检验；不能做基于长历史估值序列的估值分位、标准 DCF、RIM、DDM 的全市场实现，也做不了做空成本和分析师预期这类度量。

## 原型设计

目标是把可检验命题落成一条可运行、可扩展的管道。管道分五步：输入股票池（全市场、行业或指数成分）；算内在价值，至少两种方法并行，行业相对倍数法用行业 PE 中位数乘年化 EPS，盈利资本化法用年化 EPS 除以折现率（这是零增长 DCF 的特例）；合成错配度，早期版本用 z 值加权，最新版改成秩合成；排序，得到最贵和最便宜的两端；检验，把未来一到十二个月的收益和错配度做横截面检验，包括 Spearman 秩相关和五分位组合回测，做风险调整（收益差对市场、规模、价值因子回归取 alpha），再做稳健性（扣交易成本，以及 Bonferroni 或 DSR、PBO 多重检验校正）。

脚本骨架是主入口加核心模块。它只读打开 SQLite，不碰生产库；零外部依赖，只靠 numpy 和标准库；有三种模式，估值时点、历史横截面检验、以及两者都跑。关键函数负责内在价值与错配、预测检验、含并列平均秩的 Spearman、以及免 scipy 的 Bonferroni 阈值（用 Acklam 正态分位）。

运行时依赖 Python 3.12 加 numpy：

```powershell
py -3.12 mispricing_screener.py --mode value --db <astock.db> --out value_out.txt
py -3.12 mispricing_screener.py --mode test  --db <astock.db> --out test_out.txt
py -3.12 mispricing_screener.py --mode both  --db <astock.db> --out all_out.txt
```

统计口径上防自欺的几条要固定下来。交易成本按往返 0.30% 计（印花税、佣金、过户费、滑点），依据本地已有成本表。多重检验先声明试验数（代理数乘期限数），报 Bonferroni 阈值，上架级再上 DSR 和 PBO。防未来函数是特征只用当日及之前的数据，持有期重叠时用 Purged K-Fold 加 Embargo。可成交性上，涨跌停和一字板视为不可成交，需并报次日开盘进场口径。显著性门槛定死：宣称有效需要样本量不少于 3000、独立事件族不少于 20、且扣费后置信区间下界大于 0，否则一律判 undetermined，不宣称有效。

## 路线与切入点

六个月路线按月推进。第一月补数据并冻结口径，补齐历史 PE、PB 序列，写清有效交易日、幽灵日、复权的口径文档。第二月落地两类错配度量，相对倍数加盈利资本化，再加 PB、PS 变体，做缩尾和行业中性化。第三月搭检验管道，rank IC、五分位组合、FF3 或 FF5 风险调整 alpha、Purged 交叉验证。第四月做稳健性与成本，覆盖交易成本、涨跌停不可成交、多重检验和样本外 holdout。第五月做另类数据增强，龙虎榜、主力资金、股东户数、概念标签的短窗检验。第六月逐条裁决"错配度能否预测收益"，把有效、无效、不可判定都写成正式结论，成稿。

可展示或可发表的切入点有三个。一个是 A 股错配度复合指标的构造与样本外检验，新颖之处在于多数 A 股估值研究停在某因子有效，本文强调扣费后加多重检验下的裁决，把"不可判定"也当作正式结论。第二个是卖空约束下的错配修复，问的是 A 股无法做空这件事如何改变错配的价格含义，把做空成本和融券约束从西方文献里的可控参数变成 A 股的硬约束，检验"错配只有在下行方向才被修复"这个非对称假说，本机有龙虎榜和资金流可以套利活动做代理。第三个是估值口径与价格口径错配度的一致性检验，直接回答内在价值类度量和价格趋势类代理哪个对未来收益的预测更稳、是否互相正交。这三个切入点的共同卖点是可证伪、扣费、多重检验、诚实报告缺口，而不是"找到 alpha"。

## 局限与来源

必须写进任何对外稿的局限有几条。历史太短，全市场完整日 K 只有约 276 个交易日，十二个月期限的非重叠观测很少，IC 和 alpha 的置信区间必然很宽，多数组合难达有效的门槛，更早的历史日 K 是部分票池，不能当全市场用。估值历史缺失，快照只有几天，估值分位口径暂时不可用，错配度只能做当期横截面，历史检验被迫退回价格趋势代理，检验模式已经如实标注。绝对估值输入缺，没有账面价值、现金流、股利、负债，标准 DCF、RIM、DDM 无法诚实实现，原型用盈利资本化作代理，假设极强，结论只能定性参考。微利股极值上，EPS 趋近零时内在价值趋近零、错配会爆，原型已做缩尾，但缩尾会让极值并列饱和，说明榜单对缩尾阈值敏感，需要做阈值敏感性；最新版已改用对数缺口加秩合成加盈利质量闸来缓解。年化系数按报告期推断，忽略季节性和季度波动，有偏。成本模型偏粗，往返 0.30% 是常数，没建模涨跌停不可成交比例和冲击成本。因子的 A 股本地化构造（壳价值、ST、涨跌停）还没完成，风险调整的对照因子需要自建。分析师预期、融券成本、做空券源、股利明细本地缺，不伪造。
